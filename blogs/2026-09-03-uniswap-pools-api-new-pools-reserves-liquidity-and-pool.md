The 2020 version of this post listed newly created Uniswap v2 pairs with the first Bitquery GraphQL schema and read a pool's reserves from its token balances. That schema has been retired. This rewrite does the same four things on the current API, across Uniswap v2, v3 and v4: find new pools, learn about their tokens, read the first deposits, and read the reserves right now.
